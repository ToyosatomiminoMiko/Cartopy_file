# 地图标签的鼠标微调

地图上的文字标注写死在绘图脚本里, 想让"莫斯科"不压住铁路、让河名顺着河道挪两毫米或转个角度,
就得改几个数字重跑一次几分钟的重图. 这一页说的是把它拆成两步的做法: **地图照旧用脚本出,
标签位置与角度用鼠标在浏览器里调**, 调完存成一份入库的布局文件, 下次出图自动带上.

## 两步流程

```bash
# 1. 出图(慢, 一次就够): 仍然是一句话
python Volga/volga.py

# 2. 调标签(快, 想调多少遍都行): 只读已有的 .svg, 不重算地形
python tools/label_editor.py

# 3. 固化: 在浏览器里 Ctrl+S 存布局, 然后重跑一次脚本, 产物就带上手工位置与角度
python Volga/volga.py
```

第 3 步只需要在"改完想交付了"时做一次: 编辑期间浏览器里看到的就是最终效果, 拖动/旋转不触发
任何重算. 布局文件 (`<产物>.labels.json`) 与产物一起提交, 所以别人 clone 下来重跑脚本也能
得到同样的标签位置与角度.

编辑器不接受命令行参数: 调哪张图写在 `tools/label_editor.toml` 里(默认是伏尔加流域图, 换图只
改一行), 配置项见下节.

## 配置

全部配置在 `tools/label_editor.toml`, 启动时读一次; 相对的 `svg` 路径按仓库根目录解析, 所以从
哪个目录启动都一样:

```toml
svg = "Volga/volga_basin_topography_etopo2022_lambert_conformal.svg"  # 目标产物
port = 0             # 0 = 由系统分配空闲端口
open_browser = true  # 启动后自动打开浏览器
```

- 监听地址固定 `127.0.0.1`: 编辑器没有鉴权, 只给本机用, 所以不提供地址项;
- 只认 `svg` / `port` / `open_browser` 三个键, 拼错键名直接报错, 不会悄悄退回默认值;
- 传命令行参数同样会报错, 目标图只能改 TOML.

## 编辑器界面

`python tools/label_editor.py` 起一个只监听 `127.0.0.1` 的静态服务并打开浏览器:

- 左边是整张地图(SVG 原样渲染, 滚轮缩放、空白处拖动平移、双击回正);
- 右边是这张图上所有可编辑标注的列表, 点一条就在图上居中并选中它;
- 拖动标签即可移动; 选中后方向键微调(`Shift` 加快 10 倍, `Alt` 放慢 10 倍), 顶栏可改步长;
- 选中标签后, 拖它上方的 ⟳ 手柄即可旋转(按住 `Shift` 吸附到 15° 的整数倍); 也可以按 `[` / `]`
  或侧栏的 ↺ / ↻ 按钮按"旋转步长"转(`Shift` ×10, `Alt` ×0.1), 侧栏实时显示当前角度;
- "＋ 新增标注"(快捷键 `N`)后点地图落点、输入文字; 新标签的样式(字号/颜色/斜体/白描边/旋转)
  抄自当前选中的标签(没选中就抄列表里第一个标签), 顶栏"样式"下拉框可以另选抄哪一个标签;
- 顶栏可开"突出标签", 让标签在半透明地物上更醒目;
- `Ctrl+S` 保存布局; 未保存时关标签页会提醒; 侧栏有单条"重置"和"全部重置"(新增标注是"删除").

保存之后顶栏会提示"需要重跑脚本生成最终 SVG", 并给出对应的命令: 布局只是"期望位置", 产物要由
出图脚本重新生成才会带上它.

旋转以文字锚点为轴: 已有标签存的是**相对脚本默认角度的增量**, 脚本按河道方向自动算出来的角度
改了以后, 手工增量仍然叠在上面; 新增标注存的是绝对角度. 角度单位是度, 正值表示顺时针(SVG
约定, 与 matplotlib 的 `rotation` 反号). 把标签转回 0° 且位移也回到 0, 并且 SVG 里没有烤入
这条记录时, 编辑器会自动清掉这条多余记录.

## 布局文件与坐标系

布局文件就在产物旁边, 例如
`Volga/volga_basin_topography_etopo2022_lambert_conformal.labels.json`, 内容是"位移/旋转 +
新增标注", 字段与校验见 [reference/labels.md](reference/labels.md). 三个容易搞混的点:

- 位移单位是 **pt, y 轴向下**(即 SVG 的用户单位), 画布上一个"下移 5"对应 `"dy": 5`;
- 旋转单位是度, 正值顺时针; 已有标签存增量, 新增标注存绝对角度;
- 新增标注存的是**文字基线锚点**的绝对坐标, 与 SVG 里 `<text y>` 的含义一致, 不是文本框中心.

平移量用显示坐标叠加(不做经纬度反算), 所以改 `--dpi`、改导出尺寸后, 同样的 pt 位移在图上看起来
是一样的距离; 旋转是绕文字锚点的屏幕角度, 与 dpi 无关.

## 为什么不是改脚本里的数字

- 改数字要重跑整张图(伏尔加一张 2~4 分钟), 一轮"挪一点看一眼"要几分钟;
- 位置散落在 `CITIES` / `RIVER_LABELS` 等数据结构里, 改多了没人记得为什么这么摆;
- 布局文件是纯文本 diff, 能 review、能回滚, 也能在脚本默认位置变化后继续叠加;
- 新增标注不需要往脚本的数据结构里塞, 编辑器直接产出记录.

## 常见问题

- **编辑器里没有标签可选**: 这张 SVG 是旧产物, 绘图脚本还没给标注设 `gid`. 重跑一次脚本;
  新图种要按 [add-map.md](add-map.md) 的清单给标注加 `label_id(...)`.
- **保存后刷新, 标签又回到旧位置/旧角度**: 说明还没重跑脚本; 顶栏的 `needs_render` 提示就是
  这件事.
- **看不到旋转手柄**: 手柄只在选中标签时出现; 按 `Esc`、切到"新增标注"模式或标签被删除后都
  会隐藏. 也可以用 `[` / `]` 或侧栏按钮转.
- **带引线的标注旋转后引线不跟着转**: 标准 SVG 产物里引线是独立画师, 只认地理位置, 与移动
  标签时的情况一样; 大角度旋转要回脚本里调引线端点(字形路径回退时引线端点会跟着文字走).
- **顶栏说布局文件损坏**: 文件不是合法 JSON 或被手改坏了, 报错里有路径; 修好或删掉重来.
- **新增的文字显示成方框**: 该字不在字体子集里, 编辑器预览用回退字体; 重新出图后会内嵌正确字形.
- **新增标注的位置和大改版式后对不上**: 布局里的绝对坐标以整张画布为基准, 换画框/投影后要重调;
  已有标签用的是相对位移, 不受影响.
- **启动报错"找不到配置文件"**: `tools/label_editor.toml` 被删了或挪走了; 报错里带样例内容,
  照抄一份回去即可.
- **启动报错"不认识的键"/"port 必须是整数"**: TOML 拼错或类型不对; 只认 `svg` / `port` /
  `open_browser`, 剩下的键一律报错.
- **传了 SVG 路径却还是打开旧图**: 工具不接受命令行参数, 目标图只看 TOML 的 `svg`.
